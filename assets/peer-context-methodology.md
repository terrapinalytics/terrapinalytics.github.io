# Peer context across dashboards

Added November 20, 2026. Rankings, weights, source metric values and departure probabilities are unchanged.

All comparisons report available entity count, descriptive rank, numerical-value percentile, equally weighted arithmetic mean and median. Empty strings, null, undefined and nonnumeric values are excluded; observed zero is retained. Rank uses competition ties (1 + count ahead). For n >= 5, value percentile = 100 × (count strictly below + (tie count − 1)/2)/(n − 1). Higher numerical values always mean higher percentile, even when a lower metric is desirable. Source national-rank metrics rank lowest first; other metrics rank highest first. This is descriptive, not a performance adjustment. Rank and percentile are withheld for samples under five or when the selected entity is outside the qualifying cohort. The selected entity is included when eligible. The mean weights each entity equally, not by games, possessions, spending or enrollment.

- **Program rankings:** fixed-period, same-field comparisons within the 79-program sample, current P4 sample and current conference. EADA/NCAA and separate roster-spending sources remain separate metrics. National ranking inputs remain original provider ranks; the extra peer rank is only within the displayed sample. Historical multi-year windows and partial coverage limitations are retained.
- **Carousel:** buyout estimates compared only within tracked situations and current conference subset, explicitly labeled mixed reporting dates/estimates. Subjective probabilities and job tiers do not receive data-derived percentiles.
- **Finance:** same source family, fiscal year, metric and nominal-dollar basis. Cohorts are reporting schools among the 68 current Power Four members and reporting schools in the selected school's current conference. Group of Six school profiles also compare against the 11 ranked Group of Six schools where a value is available. Conference cohorts use current membership throughout the series. Private missing values are excluded, never zero.
- **Fouls:** same selected season, game-type, conference, location and foul-type filters; independent of name search and pagination. Minimum games retained; players additionally require 100 tracked on-court possessions for peer eligibility. Overall and same-conference cohorts plus known same-position cohorts for current players. Historical Edey-only data cannot support historical player percentiles. Rates are descriptive; referee measures are crew statistics, not individual whistles.
- **Recruiting:** same class range, recruit threshold and geographic radius for school access/capture, using the complete loaded geocoded recruit pool independently of map viewport or selected-school spatial crop. Overall mapped power-conference/Notre Dame sample and current conference. Overlapping circles are not independent and distance is city-based. Recruit ratings compare with the same class and same class/position only among loaded recruits, not the entire national recruiting universe.
- **Championships:** same season, sport, tier, title-type and weighting filters, comparing title-winning schools only. Dataset lacks all school-sport eligibility opportunities; non-winners are not silently assigned zero. Different membership tenure and sports sponsored remain limitations; this is not opportunity-adjusted success.

## Position supplement

ESPN roster API requested for 365 teams with existing 2026–27 player observations; 363 returned verified 2027-season responses, 2 failed and are recorded. 4,067/4,249 players matched by unique normalized full name plus team. Existing play-by-play IDs and ESPN roster IDs differ. No fuzzy matching or position inference. Original responses are preserved in `fouls/position-roster-sources-2027.zip`, with source URLs and join method in `fouls/player-positions-2027.json`. Collector is in `scripts/collect-player-positions.py` and reuses the preserved responses when present.

## Validation

Run `node tests/peer-context.test.cjs`. Checks cover missing/zero/tied values, rank direction, small samples, real financial source/year selection, real positional player cohorts, search-independent denominators, historical sample suppression, current P4 membership inputs, and recruiting school context. JavaScript syntax and whitespace checks also run before deployment.
